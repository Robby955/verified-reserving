    Finite witness for the stochastic BF model #

    This one-point model instantiates BF1--BF3 and the conditional prediction-error theorem. Its increments are all one, so the process variance is zero. The witness checks joint satisfiability of the new hypotheses; it is not evidence for positive process variance.
