# Roadmap: the stochastic layer

Each item is a theorem to build, with the mathlib tool it needs. Order is the build order.

1. Model. A `MackModel` structure over a probability space: the triangle as random variables `C i k : Ω → ℝ`, the filtration `D k` generated by columns `0..k` (all accident years), and the three assumptions
   (M1) `μ[C i (k+1) | D k] = f k * C i k` a.e.;
   (M2) accident years independent (`iIndepFun` over the rows);
   (M3) `Var[C i (k+1) | D k] = σ² k * C i k` a.e.
   Tool: `MeasureTheory.condExp`, `ProbabilityTheory.iIndepFun`, `ProbabilityTheory.condVar` if present, otherwise define conditional variance via condExp of the squared centred variable.
2. DONE 2026-08-24 (Stochastic.lean, `condExp_fhatRv`). Theorem 2a (Mack 1993): `μ[fhat k | D k] = f k` under (M1) in the `D_k`-conditioned form, on `{S_k ≠ 0}`, with integrability hypotheses. Tools used: `condExp_mul_of_stronglyMeasurable_left`, `condExp_finsetSum`, `Finset.stronglyMeasurable_sum`. Still to build: (M2) independence across rows implies the `D_k` form from Mack's row-conditioned assumption.
3. DONE 2026-08-24 (Stochastic.lean, `condExp_fhatRv_mul`, `integral_fhatRv_mul`, `integral_fhatRv`). Theorem 2b: `E[fhat j * fhat k | D j] = f j * f k` for `j + 1 ≤ k`, and the unconditional forms on a probability space. Tools used: `condExp_condExp_of_le`, `condExp_smul`, `integral_condExp`, `StronglyMeasurable.mono`. Required adding `D_mono : Monotone D` to `RandomTriangle`.
3b. DONE 2026-08-25 (Ultimate.lean). Mack's Theorem 1: `condExp_C_of_Mack1` (iterated (M1)), `condExp_ChatRv` (partial chain-ladder products), `condExp_ultimate_eq` (the ultimate is conditionally unbiased). Tools: `condExp_of_stronglyMeasurable`, `condExp_condExp_of_le`, `condExp_smul`, induction on the number of factors.
3c. DONE 2026-08-25 (Variance.lean). (M3) and (M2') as definitions; `condExp_sq_fhatRv_sub`: E[(fhat k - f k)^2 | D k] = σ² k / S k on {S k ≠ 0}. Tools: `condExp_mul_of_stronglyMeasurable_left`, `condExp_finsetSum` twice, `Finset.sum_ite_eq'`.
4. DONE 2026-08-25 (SigmaUnbiased.lean): `weighted_sq_dev_eps`, `condExp_wssRv` (E[W_k | D_k] = (n-k-2) σ²), `condExp_sigma2Rv` (E[σ̂²_k | D_k] = σ² for k+3 ≤ n). Original plan for reference:
   Unbiasedness of `sigma2 k` under (M1)-(M3): uses `weighted_sq_dev_at_fhat` from the deterministic layer plus conditional variance of the weighted mean. This is where the `(n-k-2)` degrees of freedom are justified.
5. Process variance of `C i (n-1)` given the data: iterated conditional variance along the row, giving `Ĉ² ∑ σ²_k/(f_k² Ĉ_{ik})` after plugging estimates. Tool: law of total variance for condExp (prove as a lemma if absent).
6. Estimation error. Mack's step replaces `(f̂_k - f_k)²` by its conditional expectation `σ²_k / S_k` and drops cross terms using 2b. State the estimator as Mack states it (the "conditional resampling" approximation) rather than as an exact identity; the exact conditional MSEP is a different object (BBMW 2006), and the catalogue records both.
7. Theorem 3 (Mack 1993). Assemble 5 and 6 into `msep` as defined in ChainLadder.lean. Then the Corollary for the total reserve with the cross terms.
8. Mack 1999 recursion equals the 1993 closed form (α = 1, unit weights): a deterministic induction on `k` using `Chat_succ`; no probability needed. This is the first catalogue row and can be done immediately.
