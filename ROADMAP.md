# Roadmap

## Current priorities

1. ODP distributional layer: add process simulators and prove bootstrap properties only under explicit distributional assumptions.
2. Observable CDR: state any resampling or linear approximation as a separate assumption before deriving an approximation result.
3. Bühlmann-Straub: add structural-parameter estimation after the conditional-moment model.
4. Bornhuetter-Ferguson: add a finite positive-variance witness for the prediction-error results.

## Build history and module-level gaps

Each item records what was built, the remaining local gaps and the mathlib tools involved.

1. DONE 2026-08-25 (Stochastic.lean, Variance.lean, Independence.lean). `RandomTriangle` carries the random cumulative triangle and a monotone filtration `D`; `RowsGenerateD` separately states that `D k` is the join of the row histories through `k`. The source assumptions are separate predicates:
   (M1) `μ[C i (k+1) | D k] = f k * C i k` a.e.;
   (M2) accident years independent (`RowsIndep`, implemented with `ProbabilityTheory.iIndep` over the row sigma-algebras);
   (M3) `μ[(C i (k+1) - f k * C i k)^2 | D k] = σ² k * C i k` a.e.
   Tools: `MeasureTheory.condExp`, `ProbabilityTheory.iIndep`.
