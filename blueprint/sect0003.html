Theorem 3.5 Mack 1999 = Mack 1993
✓
#

Uses

Lean declarations

  • VerifiedReserving.se2rec_eq_msep

For \(i \le n-1\) and \(\hat f_k \neq 0\) along the row, \(i\) steps of the 1999 recursion return exactly Mack’s 1993 estimator: \(\mathrm{se}^2_i = \widehat{\mathrm{msep}}(\hat R_i)\).
