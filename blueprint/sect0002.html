2 The chain-ladder estimators

2.1 Definitions

Definition 2.1 Contributors
✓
#

Lean declarations

  • VerifiedReserving.contributors

The accident years contributing to the development factor \(k \to k+1\) are \(i = 0, \dots , n-k-2\), those with \(C_{i,k+1}\) observed.

Definition 2.2 Column sums
✓
#

Uses

  • VerifiedReserving.T

\(S_k = \sum _{i=0}^{n-k-2} C_{i,k}\) and \(T_k = \sum _{i=0}^{n-k-2} C_{i,k+1}\).

\(\hat\sigma _k^2 = \frac{1}{n-k-2}\sum _{i=0}^{n-k-2} C_{i,k}\, (F_{i,k} - \hat f_k)^2\). The value for \(k = n-2\) (a single contributor) is an extrapolation convention in [ 1 ] , not an estimator; no theorem here uses it.

Definition 2.8 Mack’s MSEP estimator
✓
#

Uses

  • Definition 2.7
  • Definition 2.5
  • Definition 2.2

Lean declarations

  • VerifiedReserving.msep

Mack (1993), Theorem 3:

\[ \widehat{\mathrm{msep}}(\hat R_i) = \hat C_{i,n-1}^2 \sum _{k=n-1-i}^{n-2} \frac{\hat\sigma _k^2}{\hat f_k^2} \Big(\frac{1}{\hat C_{i,k}} + \frac{1}{S_k}\Big). \]

2.2 Deterministic identities

Lemma 2.9 Weighted-average form
✓
#

Uses

  • Definition 2.3
  • Definition 2.4

Lean declarations

  • VerifiedReserving.fhat_eq_weighted_average

If \(C_{i,k} \neq 0\) for every contributor \(i\), then \(\hat f_k = \sum _{i} \frac{C_{i,k}}{S_k} F_{i,k}\).

Proof ▶

Termwise: \(\frac{C_{i,k}}{S_k}\cdot \frac{C_{i,k+1}}{C_{i,k}} = \frac{C_{i,k+1}}{S_k}\).

✓
#

Uses

Lemma 2.11 Sum-of-squares decomposition
✓
#

Uses

  • Lemma 2.10

Lean declarations

  • VerifiedReserving.weighted_sq_dev

For any centre \(f\), with \(C_{i,k} \neq 0\) for every contributor, \(\sum _i C_{i,k}(F_{i,k}-f)^2 = \sum _i C_{i,k}F_{i,k}^2 - 2 f T_k + f^2 S_k\).

Proof ▶

Expand the square and use Lemma 2.10.

Lemma 2.12 Collapse at the chain-ladder centre
✓
#

Uses

  • Lemma 2.11
  • Definition 2.3

Lean declarations

  • VerifiedReserving.weighted_sq_dev_at_fhat

If moreover \(S_k \neq 0\), then \(\sum _i C_{i,k}(F_{i,k}-\hat f_k)^2 = \sum _i C_{i,k}F_{i,k}^2 - S_k \hat f_k^2\). This is the identity behind the \(n-k-2\) degrees of freedom in \(\hat\sigma _k^2\).

Proof ▶

Put \(f = \hat f_k = T_k/S_k\) in Lemma 2.11.
